What is semantic HTML?

Semantic HTML uses elements that describe the meaning and purpose of their content. For example, <nav> represents navigation and <article> represents independent content.

Page Structure Elements

These elements organise the main sections of a webpage.

Structure example

<header>

Contains introductory content such as a title, logo or navigation.

<nav>

Contains important navigation links.

<main>

Contains the main and unique content of the webpage.

<section>

Groups related content into a meaningful section.

<footer>

Contains information such as copyright, contact details and additional links.

Article and Aside Elements

The article element represents independent content, while aside contains related but secondary information.

Text Semantic Elements

These elements give meaning to words, phrases and quotations.

Text examples

The strong element shows strong importance.

The em element adds emphasis to text.

The mark element highlights relevant text.

The small element represents side comments or smaller print.

The abbreviation HTML has a full meaning inside its title attribute.

The product costs £100 £75.

Water can be written as H2O.

Two squared can be written as 22.

The event starts at 6:30 pm.

The book Clean Code was written by Robert C. Martin.

A short quotation can use the q element inside a paragraph.

Good structure makes webpages easier for people, browsers and search engines to understand.
